# Tech Intelligence Scheduling Verification

The TidyCal inline embed was tested in the deployed browser and presented a blank/broken third-party surface. The Tech Intelligence booking section therefore uses the publicly reachable direct scheduling destination instead of an embedded calendar.

The live booking action opens `https://tidycal.com/metaresults/pilot` in a new tab. This removes the broken inline area while preserving immediate access to the approved Meta Results calendar.
